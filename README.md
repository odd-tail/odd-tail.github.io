# 오드테일 첫 시안

외부 배포하지 않은 정적 사이트입니다. 설치나 빌드가 필요 없습니다.

## 미리보기

이 폴더에서 `python3 -m http.server 4173 --bind 127.0.0.1` 실행 후 http://127.0.0.1:4173 에 접속합니다.

## 내용 수정

`config.js`에서 브랜드명, 소개, 슬로건, 이미지, 링크를 수정합니다.

- `links`: 배열 순서가 표시 순서입니다. `url`을 넣고 `visible: true`로 설정하면 표시됩니다. 빈 주소와 `visible: false` 항목은 미리보기와 공개 화면 모두 숨깁니다. 준비 중인 항목을 가짜 버튼으로 표시하지 않습니다.
- 이메일은 `mailto:실제주소` 형식으로 입력합니다.
- `image`: 실제 브랜드 이미지의 경로를 입력합니다. 예: `./assets/profile.jpg`. 현재는 `assets/profile.png`를 원형으로 표시합니다.
- `shareImage`: 실제 브랜드 이미지의 절대 URL을 입력합니다. 현재는 공유 이미지를 설정하지 않았습니다.
- favicon.svg는 제공된 프로필 이미지를 원형으로 표시합니다. 프로필 이미지를 교체할 때 파비콘도 함께 교체하세요.

디자인은 `style.css`, 구조와 기본 메타데이터는 `index.html`에서 수정합니다. SNS 크롤러 중 JavaScript를 실행하지 않는 서비스도 있으므로, 브랜드명·소개·공유 이미지를 바꾼 뒤 배포할 때는 `index.html`의 title 및 메타데이터에도 반영하세요.

- `announcement`: 메인 문구전 소식입니다. 제목·본문·일정 안내·노출 여부를 수정할 수 있습니다. 실제 행사 URL이 있을 때만 `url`에 입력하세요. 빈 경우 안내 버튼은 숨겨집니다.
